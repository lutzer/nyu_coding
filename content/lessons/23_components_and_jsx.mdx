# A React Component

In the last lesson you met two JavaScript ideas: **variables** and
**functions**. Now we'll read a real React component — and you'll
see that it is just a function that returns a piece of UI.

Open the sandbox below and keep `App.js` visible on the left.

Here's the whole file:

```jsx
export default function App() {
  return (
    <div>
      <h1>Hello from React!</h1>
      <p>This paragraph is rendered by a React component.</p>
    </div>
  );
}
```

Let's ignore the two words `export default` for now (we'll come
back to them in the next lesson) and read what's left:

```jsx
function App() {
  return (
    <div>
      <h1>Hello from React!</h1>
      <p>This paragraph is rendered by a React component.</p>
    </div>
  );
}
```

Looks familiar? That's a **function** named `App`. It takes no
parameters (empty `()`), and its body (between the curly braces)
does one thing: it `return`s a value.

What's new is *what* it returns. It's not a number or a string —
it looks like HTML.

## A component is a function that returns UI

In React, **every component is a function**, and a component's job
is to **return the chunk of UI it represents**. That's really all
there is to it.

Two small conventions to notice:

- Component functions start with a **capital letter** (`App`, not
  `app`). That capital is how React tells your components apart
  from built-in HTML tags later on.
- A component doesn't take any input in this example. We'll add
  inputs — called **props** — in a later lesson. For now, the
  parentheses stay empty.

## `return` — handing back a chunk of page

Remember from the last lesson: a function's `return` is the value
it hands back to whoever called it. For a React component, that
returned value is the piece of the page the component represents:

```jsx
return (
  <div>
    <h1>Hello from React!</h1>
    <p>This paragraph is rendered by a React component.</p>
  </div>
);
```

The parentheses `( ... )` after `return` are just a wrapper so we
can spread the returned value over several lines. They are not
doing anything clever.

React calls the `App` function, takes the `<div>` it hands back,
and turns it into real HTML on the page.

## JSX — HTML inside JavaScript

Those `<div>`, `<h1>` and `<p>` tags look exactly like HTML from
Chapter 1, but they're sitting inside a JavaScript file. That mix
has a name: **JSX**.

JSX lets you write HTML-looking tags right inside your JavaScript.
It's **not** real HTML — React translates it into real HTML
elements when it renders your component.

A few small rules that will trip you up at first:

- A component must return **one** element. If you want several
  tags side by side, wrap them in a parent `<div>` (or an empty
  wrapper `<>...</>`).
- Every tag must be **closed**. Self-closing tags end with ` />`:
  `<img src="..." />`, `<br />`, `<hr />`.
- The HTML attribute `class` becomes **`className`** in JSX,
  because `class` is a reserved word in JavaScript.
- JSX comments go inside braces: `{/* like this */}`.

## Putting it together

Reading `App.js` top to bottom now:

```jsx
export default function App() {   // define a function named `App`
  return (                        // the function returns…
    <div>                         //   a <div> containing…
      <h1>Hello from React!</h1>  //     a headline
      <p>This paragraph is rendered by a React component.</p>
    </div>                        //   (end of the <div>)
  );
}
```

That's a complete React component. It's a function. It returns
JSX. React runs the function and puts the result on the page.

## Exercise

Time to write some JSX of your own. The `App` component below is
empty — it returns `null`, so the page renders nothing. Replace
`return null;` with a `return ( ... )` that hands back a `<div>`
containing:

1. An `<h1>` headline (whatever title you like).
2. An `<img>` tag with `src="https://picsum.photos/300"`, nested
   *inside* the same `<div>` as the headline.

Remember:

- A component must return **one** parent element — put both the
  headline and the image inside the same `<div>`.
- The `<img>` tag must be **self-closed**: `<img src="..." />`.
