# Assets

An **asset** is any file your page pulls in from somewhere else: an
image, a font, a sound, a video. Your HTML and CSS just point at these
files — the browser goes and fetches them.

## Local vs. remote paths

Every asset lives *somewhere*. There are two ways to point at it:

- **Remote** — a full URL that starts with `https://`. The browser
  downloads the file from another server.

  ```html
  <img src="https://picsum.photos/400/250" alt="A random photo" />
  ```

- **Local** — a path to a file sitting next to your HTML. No `https://`,
  just the file name (or a folder + file name).

  ```html
  <img src="cat.jpg" alt="A cat" />
  <img src="images/cat.jpg" alt="A cat in a subfolder" />
  ```

## Images

You already know `<img>` from the HTML chapter:

```html
<img src="cat.jpg" alt="A sleeping cat" />
<img src="https://picsum.photos/300/200" alt="A random photo" />
```

In CSS, images show up as backgrounds via `url(...)`:

```css
body {
  background: url("bg.jpg");           /* local */
  background: url("https://.../bg.jpg"); /* remote */
}
```

## Fonts

Two common ways to bring in a custom font.

**Remote — Google Fonts.** Grab a `<link>` from
[fonts.google.com](https://fonts.google.com) and paste it into your `<head>`,
then use the font by name in CSS:

```html
<link rel="stylesheet"
      href="https://fonts.googleapis.com/css2?family=Inter&display=swap" />
```

```css
body {
  font-family: "Inter", sans-serif;
}
```

**Local — `@font-face`.** Drop a font file (usually `.woff2`) next to your
page and register it yourself:

```css
@font-face {
  font-family: "MyFont";
  src: url("fonts/MyFont.woff2");
}

body {
  font-family: "MyFont", sans-serif;
}
```
