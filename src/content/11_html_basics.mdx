# HTML Basics

To build a website, there are three main languages you will learn in this
course. Each one has its own job:

- **HTML** (HyperText Markup Language) — describes the *structure* and
  *content* of a page: headings, paragraphs, images, links.
- **CSS** (Cascading Style Sheets) — describes the *appearance*: colours,
  fonts, spacing, layout.
- **JavaScript** — adds *behaviour*: reacting to clicks, loading data,
  animating things, changing the page after it has loaded.

We will start with HTML, because we need it to create the content on 
which we will apply styles later on.

## HTML Language

HTML (HyperText Markup Language) is the basic structure of every webpage.

Every HTML page is built on the same small skeleton:

- **`<!DOCTYPE html>`** — the very first line, tells the browser this is a
  modern HTML document.
- **`<html>`** — the root element that wraps everything else.
- **`<head>`** — information *about* the page (not shown on the page itself),
  such as the character encoding and the `<title>` shown in the browser tab.
- **`<body>`** — everything the visitor actually sees on the page.


## Tags and Elements

HTML is built from tags. Most come in pairs:

```html
<p>This is a paragraph.</p>
```

* `<p>` is the opening tag
* `</p>` is the closing tag (note the slash)
* Together with the content, this whole thing is called an element

## Attributes

Tags can carry extra information called attributes, placed inside the opening tag:

```html
<a href="https://example.com">Click here</a>
<img src="cat.jpg" alt="A cat">
```

Here, href and src are attributes that give the browser more instructions.
