# Intro

This website provides you with the learning resources for the coding projects of the Augment the Gallery Course. 
You can always return here for finding information and check all the lessons.

## What we will cover in this course

* In **Chapter 1** we will start with the basics of web coding. 
You will learn about the HyperText Markup Language (HTML), the Document Object Model (DOM). 
How to do styling with stylesheets (CSS) and the basics about layouting.

* In **Chapter 2** we will introduce interactivity through javascript and react. 
you will learn how to setup your IDE (Interactive Development Environment). 
You get to know the file structure of a web app.

* In **Chapter 3** we will learn how to load 3d graphics into our app, how we can load data from 
JSON files and generate grids and project pages from it. 
We will introduce how to use an ai agent to help you write code.
At the end you will also understand how to deploy your app online through netlify.

## The Editor

The **Code Editor** allows you to experiment with code examples. 
I will guide you through some examples with it. You can modify the source code 
on the left and the preview window on the right will show you the resulting webpage.

* When you get lost, you can always press the *Reset* button to revert the code. 
* The *Open Preview* button will open the preview in a seperate window, 
which you can resize to your liking.
